# 拍照識客字（hakkaocr）

用手機拍下客語文字，網站辨識出客語漢字，在照片上方標出客語拼音並用客語唸出來（六腔可切換），照片下方列出辭典解釋。

## 功能

- **拍照辨識文字**：瀏覽器內執行 Tesseract.js（繁體中文 `chi_tra`），照片不會傳到辨識伺服器，也不需要 API 金鑰。相機拍照只辨識黃色取景框內的文字；同一張圖會用不同大小辨識 2～3 次，取辭典比對最好的結果。照片中有多行字時可點選其他行，認錯字可直接修改；也可以不拍照直接輸入文字。
- **挑選要查的字**：照片上每個認出的字都可以點；點一個字查單字，再點另一個字就選取中間整段。也可以按「✂️ 調整黃框」拖曳、縮放黃框後只辨識框內文字。
- **照片上方**：客語漢字（自動切成辭典詞）、每字拼音（調號＋數字調）、🔊 客語發音。可切換四縣、海陸、大埔、饒平、詔安、南四縣；「自動發音」與「拼音顯示」可開關。點任一個詞只唸那個詞。
- **照片下方**：辭典解釋（所有讀音、詞性、釋義、例句）；辭典沒有的詞（例如「汽車」）改列單字解釋，讀音依單字組合並註明。
- **會員**：與「客語字音字形練習」「拍照學客語」共用 Supabase 帳號。
- **群組**：建立群組、6 碼邀請代碼加入、擁有者／管理員／成員三種角色、移出成員、換新代碼；管理者可看每位成員的收藏數、完成數、待複習數；成員可把收藏分享到群組相簿。
- **我的最愛**：保存照片（Supabase Storage 私有空間）、文字位置、拼音與解釋摘要，可重新播放、切換腔調。
- **複習**：收藏後隔天開始，預設漸進間隔 1→2→3→3 天，也可設定固定每 1、2 或 3 天；每張最多複習 5 次。複習時先看照片想讀音，再翻開答案。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 整個網站（單一頁面，無建置步驟） |
| `dict.json` | 14,681 個詞／字：六腔拼音、錄音檔名、釋義、例句（自動產生） |
| `tools/build_dict.py` | 產生 `dict.json`：`python3 hakkaocr/tools/build_dict.py` |
| `supabase/001_hakkaocr.sql` | 資料表、權限（RLS）、RPC 與照片儲存空間；可重複執行，不刪除任何東西 |

資料來源：教育部《臺灣客語辭典》（主網站內嵌資料，含錄音）、《臺灣客家語常用詞辭典》（g0v/moedict-data-hakka）、主網站國賽字音題庫（補單字讀音）。

## 部署

1. 在 Supabase SQL Editor 執行 `supabase/001_hakkaocr.sql`（vibe-lab 專案已於 2026-10-30 套用）。
2. 網站放在任何 HTTPS 靜態主機即可（相機需要 HTTPS），網址為主網站下的 `/hakkaocr/`。

## 已知限制

- 手寫字、直書、強烈反光或很斜的照片辨識率較低，可在結果下方手動修正。
- 「𠊎」等客語特有字不在辨識模型字表內。
- 只有《臺灣客語辭典》收錄的詞有整詞錄音；其他詞逐字播放，少數字沒有錄音時會略過。
