# 拍照學客語（objcam）

用手機拍下身邊的物品，網站辨識出是什麼，在照片上方顯示國語字詞、注音並唸出國語，照片下方顯示客語漢字、客語拼音（六腔可切換）並播放客語。

## 功能

- **拍照辨識**：瀏覽器內執行 TensorFlow.js（COCO-SSD 物體偵測＋MobileNet v2 影像分類），照片不會傳到辨識伺服器，也不需要 API 金鑰。辨識不準時可點其他候選或手動選擇。
- **國語**：注音逐字標在字下方，用瀏覽器內建語音（zh-TW）唸出。
- **客語**：四縣、海陸、大埔、饒平、詔安、南四縣。拼音與錄音取自教育部《臺灣客語辭典》（與主網站相同資料），主網站沒有的詞改用《臺灣客家語常用詞辭典》拼音，錄音逐字播放；少數現代詞（汽車、電腦等）依單字音組合，畫面會註明。
- **會員**：與「客語字音字形練習」共用 Supabase 帳號。
- **群組**：建立群組、6 碼邀請代碼加入、擁有者／管理員／成員三種角色、移出成員、換新代碼；管理者可看每位成員的收藏數、完成數、待複習數；成員可把收藏分享到群組相簿。
- **我的最愛**：保存照片（Supabase Storage 私有空間）與國語、客語資訊，可重新播放。
- **複習**：收藏後隔天開始複習，預設漸進間隔 1→2→3→3 天，也可設定固定每 1、2 或 3 天；每張最多複習 5 次。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 整個網站（單一頁面，無建置步驟） |
| `vocab.js` | 99 種物品的國語、注音、六腔客語資料與辨識標籤對照（自動產生） |
| `tools/concepts.py` | 物品清單：國語、客語漢字、COCO 標籤、ImageNet 類別編號 |
| `tools/build_vocab.py` | 產生 `vocab.js`：`pip install pypinyin && python3 objcam/tools/build_vocab.py` |
| `supabase/001_objcam.sql` | 資料表、權限（RLS）、RPC 與照片儲存空間，可重複執行 |

## 部署

1. 在 Supabase SQL Editor 執行 `supabase/001_objcam.sql`。
2. 網站放在任何 HTTPS 靜態主機即可（相機需要 HTTPS），網址為主網站下的 `/objcam/`。

## 新增物品

在 `tools/concepts.py` 加一行（國語、客語漢字、分類、COCO 標籤、ImageNet 類別編號），再執行 `build_vocab.py`。
