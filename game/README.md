# 客語尋寶家（原型）

拍下身邊的東西、圈選、確認名稱、用客語（六腔）或國語、英語唸出來，唸對就得分並收進「客家生活圖鑑」。吉祥物是原創的油桐花精靈「阿桐」。網址：`/game/`。

這是第 1 階段的可操作原型，企劃見專案文件「客語尋寶家：拍照收集客語遊戲企劃」。

## 流程

1. **拍照**：用手機內建相機或相簿；照片重新編碼，不含拍攝地點（EXIF）。
2. **圈選**：COCO-SSD 自動畫框，點一下即可；也可以用手指畫圈或用整張照片。
3. **確認名稱**：MobileNet＋COCO-SSD 給 3 個中文選項，或「都不是，我來講」（國語語音輸入、打字，有建議清單）。
4. **選語言**：客語六腔（預設自己的腔調）、國語、英語；可聽辭典示範。
5. **錄音**：點一下開始、再點一下結束，最長 6 秒，自動回放；聲音太小或太大會提示。
6. **比對**：
   - 有設定語音比對伺服器（`asr/`）：送去辨識並評分。
   - 國語、英語：瀏覽器支援時用內建語音辨識同步比對。
   - 其他情況（目前客語都是）：「自己聽聽看」對照示範，送出後標為待驗證。
   - 不確定時顯示「阿桐聽到的是…」，可以再唸、改名稱或申訴；唸錯不扣分。
7. **得分與圖鑑**：確認名稱 +10、唸對 +30、一次就對 +10、圖鑑新物品 +20、新腔調／語言 +20、待驗證先給 +10、每日任務 +30；同一張照片或同一段錄音重複送出不加分。

另外有：首頁等級與連續天數（每週可休 2 天不歸零）、每日三任務、五冊圖鑑與八格印章（六腔＋國＋英）、好友週榜（原型為示意）、字級三段、阿桐語音導引開關、資料使用同意（可撤回）。

## 資料（原型只存在本機）

依企劃的 `game_*` 資料表欄位存在 localStorage：`captures`（照片雜湊、尺寸）、`regions`（正規化框、多邊形、圈選方式）、`labels`（模型、前 3 名猜測、最後名稱、來源）、`recordings`（語言、腔調、格式、取樣率、長度、音量、第幾次、辨識文字、分數、判定、同意）與積分紀錄。照片、裁切圖、錄音存在 IndexedDB。「設定 › 進階」可匯出 JSON。

下一步接上 Supabase：建立 `game_*` 資料表與私有 bucket，積分改由 Edge Function 寫入。

| 檔案 | 說明 |

| `index.html`、`game.css`、`game.js` | 遊戲頁面 |
